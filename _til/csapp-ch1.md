CSAPP ch1.
컴퓨터 시스템 : 하드웨어 + 시스템 소프트웨어

컴파일 : 어떤 언어로 쓰인 프로그램을 다른 언어의 동등한 프로그램으로 번역하는 것  
- C언어 프로그램을 기계어로 변환하는 과정 소개  
- 전처리->컴파일->어셈블->링크  
- 다음 hello.c 파일을 기준으로 설명하겠다  
```c
#include <stdio.h>
int main(){
	printf(“hello, world!\n”);
	return 0;
}
```

  - 전처리 : .c 소스 텍스트 -> 전처리된 소스 텍스트(.i)  
		ㄴ 컴파일 이전의 순수한 텍스트 변환 단계. #으로 시작하는 지시자만 처리  
		ㄴ 
		
	* 모든 컴파일 과정이 이러한 것은 아니다. 어셈블리로 작성한 코드는 고급 언어를 어셈블리로 변환하는 컴파일까지의 단계는 필요하지 않을 것이고 기계어로 직접 실행 파일을 작성하는 것도 가능하다. 또한 고급 언어라 하더라도 Go, Rus, Java 등에는 독립된 전처리 단계가 없고 Java의 JIT 컴파일과 같이 컴파일 과정이 다른 경우도 있다.
